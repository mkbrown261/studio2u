# Studio2U connector package

Prepared portable OpenAI and Claude Code metadata for the same read-only OAuth MCP endpoint. No marketplace listing or provider approval is claimed. Use Label World → AI Connections for the supported direct MCP setup and explicit selected-label consent.

OpenAI package conventions verified: https://developers.openai.com/plugins/build/plugins
Claude manifest conventions: https://code.claude.com/docs/en/plugins-reference

Claude local testing (requires installed Claude Code): `claude --plugin-dir ./plugins/studio2u`, then `/mcp`; run `claude plugin validate ./plugins/studio2u --strict` before publication. OpenAI public distribution requires remote MCP submission/review; no invented registered application ID is included. Optional curated marketplace distribution is not configured automatically.

This package does not enable website subscription inference, writes, approvals or full autonomous employees. Knowledge is discovered from authenticated MCP resources using the existing ICM registry. All23 complete skill contracts retain their designed status.
