# Music Research, Virality and Social Automation

## A&R discovery engine
Configure label genre/subgenre (including regional drill variants), territories/cities, emerging vs established artist targets, public source allowlist and budget. Discover via licensed/chart feeds, permitted platform APIs and attributable publication sources: official rankings, public release info, independent music media, approved SoundCloud/Bandcamp/YouTube sources, regional DJs and playlist curators. **No scraping or unauthorized hashtag crawling**. Research supports query, scheduled monitoring, dedup, source citation, observed timestamp, per-source coverage limits and changes over time.

## What a useful artist/record dossier contains
Track/artist IDs, source links, first observation, location/genre evidence, release timeline, publicly verified platform metrics *with date and source*, posting formats, creator adoption where observable/allowed, chorus/intro structure *as lawful high-level analysis*, artist engagement growth, editorial/industry signals, commercial relevance and known uncertainties. Score using explainable weighted factors with data-quality indicators. Never infer authentic streams from one viral screenshot.

## Research methodology for successful records
Sample viral and nonviral comparable releases. Analyze and compare release timing, audience fit, opening seconds, memorable sections, creator reuse, placement, social framing, release cadence, platform discovery and post-release growth. Note confounders (paid ads, label spend, influencer partnerships, existing fanbases, playlist placements) and survivorship bias. Label causal claims as unverified unless supported. Date-stamp evidence; avoid copied third-party copyrighted lyrics/full recordings.

## Marketing campaign architecture
One `campaign` per release or artist objective, with target audience, territories, brand voice, approved song hook candidates, KPI goals, budget, approved accounts, channel strategy, creative themes, captions, CTA, posting calendar, review status and analytics. Use platform-safe metadata and discoverability practices rather than promising SEO guarantees or hashtag hacks. Track impressions/views, retention where available, click-through, saves, completion, conversions and confidence of attribution; never manufacture analytics.

## n8n and Tally
Tally = optional configurable onboarding, collaborator intake, content request and audience feedback forms. n8n = optional orchestrated webhook/notification/CRM/approved publishing **integration helper**; do not use n8n as authoritative catalog, secret store or unrestricted permission engine. Authenticate incoming webhooks, deduplicate deliveries, apply tenantId and authorization at Studio2U API. Use Sheets only as export/import integration, not source of truth.

## Social publishing flow
`IDEA -> DRAFT -> CREATIVE_PENDING -> REVIEW -> OWNER_APPROVAL -> SCHEDULED -> PUBLISHING -> POSTED` or `FAILED/BLOCKED`. First milestone can export downloadable media, captions, post calendars and manual handoff. Real posting requires approved OAuth/provider scope, account eligibility, current API capabilities and approval. Store real post ID, URL, timestamp, provider response; do not show POSTED without provider acknowledgment.

## Content rights
Use user's original and licensed recordings/footage; a viral clip does not grant copying/reposting rights. Artist/subject likeness requires consent. Audio rights and permitted uses differ across organic vs paid ads and across platforms. Reviewer must apply applicable provider and use-rights checks before publishing.
